## Features

- Modern Next.js 14 architecture
- Interactive 3D components using React Three Fiber and Spline
- Advanced animations powered by GSAP and Framer Motion
- Smooth scrolling with Lenis
- Responsive design across devices
- Hero, featured work, projects, contact, and particle-effect sections

## Tech Stack

- **Framework:** Next.js 14
- **3D Graphics:** React Three Fiber, React Three Drei, and Spline
- **Animations:** GSAP, Framer Motion, and React Spring
- **Styling:** Tailwind CSS
- **Utilities:** Lenis and Parallax.js

## Installation

```bash
git clone https://github.com/RakeshK325/Rakesh_Portfolio2.git
cd Rakesh_Portfolio2
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
npm run build
npm start
```
